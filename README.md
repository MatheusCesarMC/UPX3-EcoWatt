# ☀️ EcoWatt

## Simulador de Potencial de Energia Solar

O **EcoWatt** é um projeto acadêmico desenvolvido para a disciplina de UPX 3, relacionado ao **ODS 7 - Energia Limpa e Acessível**.

A proposta do projeto é apresentar, de forma simples e acessível, uma estimativa do potencial de utilização de energia solar em um imóvel.

---

## 🎯 Objetivo

O objetivo do EcoWatt é permitir que o usuário faça uma simulação básica do potencial de geração de energia solar de um imóvel a partir de algumas informações.

O sistema busca demonstrar como a utilização de energia solar pode contribuir para a redução do consumo de energia convencional e para um uso mais sustentável dos recursos energéticos.

---

## ⚙️ Funcionalidades

O EcoWatt permite informar:

- Consumo mensal de energia em kWh;
- Área disponível para instalação dos painéis solares;
- Localização do imóvel;
- Valor aproximado do kWh.

A partir desses dados, o sistema apresenta:

- Quantidade estimada de painéis solares;
- Potência instalada estimada;
- Geração mensal de energia;
- Percentual estimado do consumo atendido;
- Economia mensal;
- Economia anual;
- Consumo que ainda não seria atendido;
- Tempo aproximado de retorno do investimento;
- Barra visual mostrando o percentual do consumo atendido.

O site também apresenta algumas informações e dicas relacionadas à energia solar e à eficiência energética.

---

## 🌱 Relação com o ODS 7

O projeto está relacionado ao **Objetivo de Desenvolvimento Sustentável 7 (ODS 7)**:

> **Energia limpa e acessível**

O EcoWatt busca incentivar o conhecimento sobre fontes renováveis de energia, principalmente a energia solar, além de apresentar possibilidades de economia e eficiência energética.

---

## 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias básicas de desenvolvimento web:

- HTML5
- CSS3
- JavaScript

Não são utilizados banco de dados ou frameworks externos.

---

## 🧮 Como funciona a simulação

O sistema utiliza os dados informados pelo usuário para realizar uma estimativa simplificada.

São considerados fatores como:

- Área disponível para os painéis;
- Potência estimada dos painéis;
- Média de horas de sol da localização selecionada;
- Eficiência estimada do sistema;
- Consumo mensal informado;
- Valor aproximado da tarifa de energia.

Os resultados são apresentados de forma automática na página.

---

## ⚠️ Observação

Os valores apresentados pelo EcoWatt são **estimativas desenvolvidas para fins acadêmicos**.

O sistema não substitui uma análise técnica ou um dimensionamento profissional de um sistema fotovoltaico.
